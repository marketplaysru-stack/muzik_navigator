# Музыкальный навигатор (VK + Telegram)

Автопостер для сообщества ВКонтакте: публикует 2 поста в сутки
(06:00 и 18:00 по Москве) на музыкальные темы. Берёт новости из RSS,
переписывает их через Groq (перевод на русский + пересказ своими словами)
и публикует на стену группы. Управление — через Telegram-бота.

## Запуск

1. `pip install -r requirements.txt`
2. Задай переменные окружения (см. ниже)
3. `python main.py`

## Переменные окружения

- VK_ACCESS_TOKEN — групповой токен VK (право wall)
- VK_GROUP_ID — числовой ID группы
- TG_BOT_TOKEN — токен Telegram-бота
- ADMIN_IDS — твой Telegram ID (можно несколько через запятую)
- GROQ_API_KEY — ключ Groq
- GROQ_MODEL — модель Groq (по умолчанию llama-3.3-70b-versatile)
- TZ — Europe/Moscow

## Команды Telegram-пульта

/post — опубликовать сейчас
/status — состояние
/feeds — список фидов
/addfeed URL — добавить фид
/rmfeed URL — удалить фид
